# Prodentis, site du centre dentaire

Site statique (HTML, CSS, un petit fichier JavaScript), sans étape de compilation. Ouvrir `index.html` dans un navigateur suffit.

## Pages

- `index.html` : accueil
- `service.html` : services et spécialités
- `cabinet.html` : le cabinet et l'équipe
- `demarche.html` : démarches et soins
- `contact.html` : coordonnées, plan et urgences
- `mentions-legales.html` : mentions légales

## À compléter avant mise en ligne

- Lien Doctolib : remplacer `https://www.doctolib.fr/` par la page du cabinet (recherche dans tous les fichiers HTML).
- Mentions légales : les champs marqués « [à compléter] » (SIRET, directeur de la publication, hébergeur, numéros RPPS).
